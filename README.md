# AI GitHub Project Explainer

AI GitHub Project Explainer is a Streamlit-based application that analyzes
public GitHub repositories and explains their project structure, files,
technologies, and overall working.

## Features

- Enter a GitHub repository URL
- Fetch repository information
- Display project structure
- Analyze source-code files
- Generate AI-based project explanations
- Explain individual files
- Simple Streamlit interface

## Technologies

- Python
- Streamlit
- GitHub REST API
- OpenAI API
